# Fault detection

Owner: Mithil Rajapakse (electrical engineering).

## Purpose

Catch inverter faults and unsafe settings from the readings the Edge Unit already collects, and raise an alert the dashboard can show. Examples we expect to look for, once the pilot logs are in hand: a stuck export limit, or measurements that do not fit a healthy inverter.

## Planned contents

- A written list of checks, agreed with the installer and with our utility contact
- A detector that runs on Edge Unit readings
- Alert records for the dashboard

Not implemented yet. We will not invent fault labels before we have seen real logs from the pilot home.
