# Dashboard

Owner: Senesh Fernando (software).

## Purpose

Two web views. The household sees today's schedule and the savings report. The utility sees the Edge Units as one virtual power plant: exports, energy held in batteries, and transformers that are close to an overload.

## Planned contents

- A Streamlit app as the first version
- A household page
- A utility page, filled from the scheduler, the grid simulation and fault detection
